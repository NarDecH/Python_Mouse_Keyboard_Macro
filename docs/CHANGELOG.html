✨ เพิ่มใหม่

  • 🎨 สีแถวตามหมวด Action — เงื่อนไข = สีเหลืองอ่อน, คีย์บอร์ด = สีม่วงอ่อน, Action พิเศษ (Image/Pixel/Launch/Beep/Clipboard/ตัวแปร) = สีฟ้าอ่อน, แถวเมาส์ = แถบขาว-ฟ้าสลับเหมือนเดิม — อ่านสคริปต์ยาวแยกกลุ่มได้เร็ว (ไม่มีผลกับการเล่น)

  • 📁📂 ย่อ/ขยายกลุ่มใต้หัวข้อ Section — เมนูขวาบนหัวข้อ → ย่อกลุ่ม: แถวสมาชิกหายจากจอ (หัวข้อขึ้นป้าย (ย่อ N แถว)) แต่ถูกเล่นตามปกติทุกอย่าง — กดซ้ำขยายคืนลำดับเดิมเป๊ะ

🔒 กันข้อมูลหาย

เวอร์ชัน 1.21.0

29 กันยายน 2026

✨ เพิ่มใหม่ (ดึงจาก ROADMAP)

  • 🔁 If Loop (เงื่อนไขนับรอบ) — Additional = เลขรอบ N เช่น 3: รอบที่ 3 ขึ้นไป → ข้ามแถวถัดไปจำนวน N (คอลัมน์ Repeat) — เหมาะกับ "รอบแรก setup รอบถัดไปข้าม" · ทำงานทั้ง GUI และ CLI
  • 🕐 If Time (เงื่อนไขเวลา) — Additional = HH:MM เช่น 22:30: ผ่านเวลากำหนดของวันนี้แล้ว → ข้าม N แถวถัดไป (Repeat) · ทำงานทั้ง GUI และ CLI
  • 🗂️ หัวข้อ Section (จัดระเบียบตาราง) — คลิกขวา → "เปลี่ยนเป็นหัวข้อ Section" / "เพิ่มหัวข้อ Section": แถวเป็นป้ายชื่อกลุ่มสีเทาเข้ม ไม่ถูกเล่น ไม่นับเลขลำดับ ไม่หน่วง — สคริปต์ยาวอ่านง่ายขึ้นทันที
  • 📐 กฎเดียวของเงื่อนไขทั้งหมด — คอลัมน์ Repeat ของแถวเงื่อนไข = จำนวนแถวที่ข้าม เสมอ (If Image / Else If Image / If Loop / If Time)

🐛 แก้ (จากการรันเดโม่จริง)

  • CLI เล่นแถวเงื่อนไขซ้ำเป็น action — เงื่อนไขไม่ทำงาน (ยังไม่ถึงรอบ/เวลา) เดิมไหลลง do_step แล้วโดนเตือน "ยังไม่รองรับใน CLI" → แถวเงื่อนไข continue เสมอ พร้อม print เหตุผลทุกกรณี
  • CLI เช็คการข้ามหลังดีเลย์ — แถวที่ถูกสั่งข้ามเดิมยังหน่วงตาม Mins/Secs ก่อนถูกข้าม → ย้ายไปเช็คก่อนดีเลย์ เท่ากับ GUI

📘 เอกสาร + 🧪 ทดสอบ

  • TUTORIAL บทที่ 5B ใหม่ · เดโม่ examples/10_conditions_v21.json (ทดสอบรัน 3 รอบจริงแล้ว)
  • เพิ่ม TestConditionsV21 + TestSectionsGui + TestV21GuiPlay (เล่นจริงผ่าน player) + TestV21CliLoop → 198 unit + 11 E2E tests ผ่านหมด
