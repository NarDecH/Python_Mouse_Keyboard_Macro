## 第 1 章 — インストールと初回起動

**完成品 .exe（推奨）：** [Releases](https://github.com/NarDecH/Python_Mouse_Keyboard_Macro/releases/latest)
ページから `AutoMouseMacro.exe` をダウンロードしてダブルクリック — Python 不要。

**ソースから実行：**

```bash
py -m pip install -r requirements.txt   # pynput（画像クリックは opencv-python と Pillow が別途必要）
py auto_macro.py                        # または run.bat
```

メイン画面は表 — 1 行 = 1 イベント：
`有効(☑) / # / X / Y / 動作 / 追加 / 分 / 秒 / 繰り返し`

安全に始める：`examples/01_auto_typer.json`（文字入力のみ、クリックなし）を読み込み
▶ START を押す。

## 第 2 章 — 最初のスクリプトを録画

1. **RECORD**（F9）を押す — リスナーがマウスクリック・キー入力・スクロールをすべて記録。
2. 操作を一通り行い、もう一度 F9（または STOP）。
3. 行を確認：アイドル時間は遅延（秒）に、スクロールは Scroll Up/Down 行になる。
4. セルをダブルクリックして座標/遅延を微調整し、**START**（F6）を押す。

## 第 3 章 — 再生オプション

| 操作 | 意味 |
|---|---|
| START / F6 | 有効（☑）の行を 1 回再生 |
| REPEAT | STOP まで繰り返し |
| 「Loop forever」/ F10 | 無限ループ |
| Loops 欄（0 = 無制限） | スクリプト全体を N 回再生 |
| 速度 0.25×–4× | 遅延をこの倍率で割る |
| Shuffle / 行 % (v1.10) | 毎回ランダム順 / ランダム部分集合 |
| マウス位置を復元 | 終了後、START 時の位置に戻す |

停止手段 — すべて約 50 ms で反応：**STOP ボタン / どこでも F8 / Esc / Ctrl+C**。
押しっぱなしになったキーやマウスボタンは自動で解放される。

## 第 4 章 — アクション一覧

**マウス：** 左/右/中央クリック + 押す/離す、ダブルクリック、Ctrl/Shift/Alt+クリック、
Scroll Up/Down（追加欄にホイール目数）、マウス移動、オフセット移動、
カーソル保存/復元。

**キーボード：** タップ/押す/離す — 追加欄は `a`、`5`、`space`、`enter`、`esc`、
`ctrl`、`shift`、`alt`、`win`、`f1`–`f12`、矢印、`pgup`、`prtsc`、VK コード（例 `27`）、
組み合わせ `Ctrl+W`、`Ctrl+Shift+T`、`Win+D`（v1.20.4）に対応。物理キーはレイアウト非依存。

**拡張 (v1.5+)：** 文字入力（タイ語+絵文字、Unicode 入力 — どのキーボード配列でも正確）、

変数設定 (v1.19)、画像クリック / 画像待ち（`opencv-python Pillow` が必要）、
ピクセル色待ち (v1.18)、If Pixel Color / Read Pixel Color / If Variable (v2.5)、
カスタムプラグイン (v1.16)。

画像アクションの検索範囲構文：`button.png@100,200,300,400` = この枠内だけ検索、
`#90` = しきい値 90%。

## 第 5 章 — 条件分岐：If Image / Else If Image (v1.17–1.18)

スクリプトに**自分で判断させる**：

```text
行 1   If Image (btn.png)        ← 判定
行 2-3 ...A グループ（見つかったとき再生）
行 4   Else If Image (btn.png) 繰り返し = 2
行 5-6 ...B グループ（見つからないとき再生）
```

- 見つかった → A グループを再生し、Else 行が B グループをスキップ。
- 見つからない → A グループをスキップ（If 行の繰り返し数）し、B グループを再生。
- 全共通ルール：**条件行の「繰り返し」列 = スキップする行数。**

ピクセル色待ち：追加欄 `x,y #RRGGBB`（例 `300,300 #ffffff`）— 一致するまで待つ
（最大 30 秒、`60s` で上書き可）。

**If Image リトライ窓 (v2.4)：** 追加欄の末尾に `Ns`（例 `img.png 5s`）を付けると、
決定まで最大 5 秒再チェック — 読み込み中のページに有効。

## 第 5B 章 — 周回/時刻条件 + セクション見出し (v1.21–1.22)

**If Loop** — 追加欄 = 周回数 `3`：3 周目以降、後続 N 行（繰り返し数）をスキップ。
「1 周目だけ初期化、後は省略」に最適。

**If Time** — 追加欄 = `HH:MM`（例 `22:30`）：当日その時刻を過ぎたら N 行スキップ。
ツールバーの **🕐 現在時刻 (+15 分)** ボタン (v1.22) で一発入力。

**セクション見出し** — 右クリック →「Section header に変換」：再生せず・カウントせず・
遅延もしないグループ見出し行。**グループ折りたたみ/展開** (v1.22)：見出しを右クリック →
折りたたむ — メンバーは表から消える（見出しに `(ย่อ N แถว)` と表示）が
**再生は完全に同じ**；展開時は元の順序どおり。折りたたんだ見出しを削除すると
先に自動展開 — 行が失われることはない。

**行の色 (v1.22)：** 条件 = 薄黄 · キーボード = 薄紫 · 特殊 = 薄青 ·
マウス行はシマシマのまま — 見た目だけ。

**練習：** `py auto_macro.py examples/10_conditions_v21.json --loops 3` を実行 —
3 周目に「round 3+」行が消えたら If Loop の動作です。

## 第 11 章 — トラブルシューティング

| 症状 | 対処 |
|---|---|
| マウスが動かない | 管理者として実行（ゲーム/管理者ウィンドウは入力を遮る）；設定で 🧪 セルフテスト |

### AND 条件 (v2.6.0)

どの主条件にも追加欄で `&&` を付けられる — **全パーツが真である必要**があり、
一つでも偽なら後続 N 行（繰り返し数）をスキップ。以前と同じ唯一のルール：

```text
If Image        img.png && 300,300 #ffffff && n > 5
                ← 画像が見つかり かつ ピクセル色が一致 かつ 変数 n > 5
If Pixel Color  300,300 #ffffff && 400,400 #000000   ← 両方の点が一致必須
If Variable     n > 5 && code = A-1                  ← 複数変数を同時比較
```

タイムアウト token は `&&` と併用可（`img.png 5s && ...` は決定前 5 秒再チェック）、
`--validate` は `&&` を理解し、壊れたパーツを 1 行ずつ報告。

### Block Start / Block End — 条件ブロックとサブループ (v2.6.0)

`🔷 Block Start` → `🔷 Block End` のアクション対が行のグループを包む（最大 8 段ネスト）—
コマンドは Block Start の追加欄に書く：

```text
(空)                 常に開く — 構造用
if img.png           条件が偽 → ブロック全体をスキップ（括弧数えで対の End を特定）
if n > 5             変数 / ピクセル / 画像条件、&& の混在可
until img.png        サブループ：End の後、画像が見つかるまで戻って繰り返す（最大 1000）
until n >= 5 max 20  n >= 5 までループ、最大 20 周 — その後抜ける
max 10               条件なし — ブロック本文を 10 回繰り返す
```

If Image と違い**行数を数える必要は一切ない** — スキップ/戻りは Start/End の対に従い、
ブロック内の編集は安全。`--validate` が再生前にペア一致・ネスト深度・追加欄形式を検査。
デモを試す：`py auto_macro.py examples/12_blocks.json`
（スキップ / 5 まで数えるサブループ / 2 段ネスト — Beep のみで安全）。

## 第 13 章 — v2.x の新機能まとめ

### 13.1 拡張 (v2.0–2.3)
- **エンジンと GUI を分離** — `macro_engine.py` は純 Python（Tk なし）；軽量の
  `engine_cli.py` で直接実行 · 🔌 ツールバーボタンでプラグインフォルダを開く ·
  プラグインマーケット：[PLUGINS.md](PLUGINS.md)。
- **📤 Export Bat メニュー** — 保存済みスクリプトの隣に `.bat`（Windows）+ `.sh`
  （Linux/macOS）ランチャーを生成；ダブルクリックで実行（`--loop` などの引数を転送）。

### 13.2 堅牢性 (v2.4)
- **自己修復グローバルホットキー** — 死んだリスナーを検出して自動再起動
  （10 秒に 1 回へ制限）、ステータスバー/ログで告知。原則：STOP は常に使えること。
- **安全タイムアウト** — 設定「N 分再生したら自動停止」（1–720）· CLI：`--max-minutes N`。
- **If Image リトライ窓** — 末尾に `Ns`（例 `img.png 5s`）を付け決定前に再チェック。
- **複数行選択** — Ctrl/Shift+クリック後 Delete で一括削除（取り消し可）。
- **スケジュールのプロファイル選択** — 再生時に読み込むプロファイルを指定；
  設定に現在の予定を表示。
- **`--validate`** — 再生せず問題行をすべて報告（見つかれば終了コード 1）。
- 画像検索のテンプレートキャッシュ — 1000 周で .png を 1000 回読まない。

### 13.3 完全な条件 + 使いやすい表 (v2.5)
- **If Pixel Color** — 点の色条件：一致 → 続行、不一致 → N 行スキップ（`Ns` で先に再チェック）。
- **Read Pixel Color** — 点の色を `{名前}` に保存（追加欄：`名前 x,y`）。
- **If Variable** — 変数比較：数値（`round > 5`）やテキスト（`code = A-1`、`msg ~ failed`）。
- **Image Click が `{img_x}/{img_y}` を設定** — 見つかった画像からの相対クリック。
- **Set Variable で `rand a-b`** — `luck = rand 1-100` が乱数を保存。
- **ドラッグで並べ替え** — 押したままドラッグ；カーソルの上半/下半で前/後に挿入；自動スクロール；
  選択全体をまとめて移動；折りたたみグループ上へのドロップは拒否。
- **やり直し (Ctrl+Y) + 完全な元に戻す** — セル編集も可 · 各行に **Note 列** ·
  Ctrl+F で **検索して全置換**。
- **新プラグイン 4 個** — Screenshot · Toast · Write Log · Ask Input
  （`ctx["vars"]` がスクリプト変数を共有）。

### v2.7–v2.8 の新機能
- **4 か国語ドキュメント** — タイ語/英語/中国語/日本語。
- **.ahk 連携** — メニュー 🔀 でエクスポート/インポート（Send/Click/MouseMove/Sleep/Run）·
  v2.8 は変数も双方向：`Set Variable` → `n := 5`、`If Variable` → `if (n > 5)`；
  `n := 0` / `n += 2` / `if (n > 5)` を行に戻せます（`x := y` → `x = {y}`）。
- **時刻ごとにプロファイル指定** — `08:00, 12:30=朝の仕事, 22:00`（時刻になったらそのプロファイルを自動読み込み）。
- **コミュニティプラグイン 3 個** — Random Pause（ランダム休止）· Counter（カウンタ変数）·
  Open URL（Web を開く）+ プラグイン投稿用 issue テンプレート（基準は docs/PLUGINS.md）。

---

- **ブロック折りたたみ (v2.8.1)** — Block Start 行を右クリックすると、対応する Block End
  までの行を折りたためます（セクションと同じ仕組み）— 非表示の行も再生・保存されます。
- **検証ボタン (v2.8.1)** — メニュー 🔍 Validate は `--validate` と同じエンジンで
  スクリプト全体を検査し、"行 N: 理由" をウィンドウに表示します。

---

- **START 再生前チェック (v2.9.0)** — START を押すと `validate_rows` が自動実行：問題が
  あれば "問題のある行をスキップして再生しますか？" と確認 — 確認 = 正常な行だけ再生、
  キャンセル = 修正に戻る。全行が問題なら何も再生しない（サイレント失敗の撲滅）。
- **すべて折りたたむ / すべて展開 (v2.9.0)** — 右クリックメニュー："すべて折りたたむ" は
  セクション + ブロックを一括折りたたみ（外側グループが上から順に内側を取り込み）；
  "すべて展開" は折りたたまれた見出しを順に展開し、元の順序ぴったりで復元します。
- **.ahk 双方向ブロック対応 (v2.9.0)** — エクスポート：`if n > 5` → `if (n > 5) { … }`、
  `max 3` → `Loop, 3 {`、`until n >= 5` → `Loop { … } Until, n >= 5`（条件は `&&` で結合、
  テキスト検索 `~` → `InStr()`）；画像・色の条件は翻訳不可ならブロック全体がコメントに —
  迷子の波括弧なし。インポートは 3 形式すべて Block Start/End 行に戻せます。

## v2.15.0 — 新機能

- **▶ グループ単位の再生** — Section 見出し行を右クリック → "▶ เล่นกลุ่มนี้อย่างเดียว"
  （このグループだけ再生）：そのグループ内の有効（☑）行だけを次の見出しまで再生して
  自動停止。START と同じプレイヤー経路（validate/STOP/ハイライト/log/ループ数すべて有効）
  なので、他の行を手で無効化する必要はありません。
- **折りたたまれた行も完全に再生** — v1.22 以来の約束どおり；有効行のないグループ =
  ステータスバーに警告して静かに終了、再生は開始しません。
- **CLI `--only-section ชื่อ`** — 見出し名を完全一致で検索 → 行範囲 + 件数を表示して
  そのグループだけ再生；見つからない = 警告して全行を通常どおり再生（フル再生と同じ
  経路なので `--queue`/watchdog とも組み合わせ可能）。
