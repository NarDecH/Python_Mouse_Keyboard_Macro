## [1.8] — 2026-09-28

### 🐛 แก้ปุ่ม STOP (ตรวจสอบต่อจาก v1.7.1 — เจอจุดที่ 5)
5. **Global Hotkey ไม่ทำงาน (สาเหตุรากของปัญหา)** — ทดสอบกด F8 จริงพบว่า
   `GlobalHotKeys` ของ pynput 1.8.x บนบางเครื่อง **ไม่ยิง callback แม้กดคีย์จริง**
   (เริ่ม listener ได้ `alive=True` แต่เงียบ) ขณะที่ `keyboard.Listener` ธรรมดารับเหตุการณ์
   ได้ปกติ → **เปลี่ยนทั้ง GUI และ CLI ไปใช้ `keyboard.Listener` จับคู่คีย์เอง**
   ทดสอบจริงแล้ว: F8 กลางดีเลย์ 60 วิ หยุดภายใน 0.1 วิ ✅
- **CLI ปล่อยคีย์ค้าง** — ตอนหยุดจะ release คีย์/ปุ่มเมาส์ที่กดค้างไว้เหมือน GUI (เดิมไม่ปล่อย)
- **CLI หยุดทันทีระหว่างดีเลย์** — เดิมใช้ `time.sleep()` บล็อกยาว → แบ่งชิ้นละ 50 ms
- **CLI แจ้งสถานะถูกต้อง** — เดิมถูกหยุดกลางคันแต่พิมพ์ "จบแล้ว ✔" → แยก "ถูกหยุดโดยผู้ใช้"
- **Type Text ใน CLI หยุดกลางประโยคได้** — เช็ค running ทุกอักขระ

### ✨ เพิ่มใหม่
- **📝 ระบบ log การเล่น** — บันทึกทุกเหตุการณ์ลง `macro_log_วันที่.txt` (หมุนรายวัน):
  `[START]` เริ่มเล่น, `[STEP]` รอบ/แถว/action/เวลาที่ใช้, `[STOP]` หยุดโดยผู้ใช้,
  `[END]` จบครบ — ใช้ทั้ง GUI (เปิด/ปิดได้ใน Settings, จำค่าใน macro_conf.json)
  และ CLI (ปิดด้วย `--no-log`) ตัดเก่าอัตโนมัติเหลือ 500 บรรทัดไฟล์ละ
- **`--stop-file` สำหรับ CLI** — สร้างไฟล์ตามพาธที่ระบุเมื่อไรโปรแกรมหยุดทันที
  ใช้ควบคุมจากสคริปต์อื่น/Task Scheduler และใช้ทดสอบ end-to-end ได้
- **หยุดจากคอนโซล** — ในหน้าต่าง CLI กด Esc หรือ q ก็หยุดได้ (นอกจาก F8/Ctrl+C)

### 🧪 ทดสอบ
- เพิ่ม 7 tests ระบบ log (เขียน/ตัดความยาว/โยงกับ CLI/`--no-log`) + เขียน test hotkey ใหม่
  ให้ตรงกับ Listener → รวม **63 tests ผ่านหมด**
- ทดสอบจริง end-to-end: สคริปต์ Press ctrl + ดีเลย์ 60 วิ + กด F8 กลางทาง →
  หยุด t=3.1s, ตรวจ `GetAsyncKeyState` ยืนยันไม่มี Ctrl ค้าง, log บันทึก `[STOP]` ถูกต้อง

## [1.7.1] — 2026-09-27

### 🐛 แก้ปุ่ม STOP (ตรวจสอบและแก้ 4 จุด)
1. **หยุดไม่ทันทีระหว่างดีเลย์** — เดิม `time.sleep()` บล็อกทั้งช่วง (แถวที่ตั้ง Mins ไว้เยอะ
   กด F8 แล้วต้องรอจนหมดดีเลย์ก่อนถึงหยุด) → เปลี่ยนเป็น `_sleep_check()` แบ่ง sleep
   ชิ้นละ 50 ms เช็คการหยุดทุกชิ้น — หยุดภายใน ~50 ms เสมอ
2. **เล่นซ้อน 2 เธรด** — กด START ระหว่างเธรดเก่ายัง sleep อยู่ เธรดเก่าตื่นมาเห็น
   `running=True` ของรอบใหม่แล้วเล่นต่อ → เพิ่ม generation counter (`_play_gen`)
   เธรดเก่าจะหยุดเองทันทีที่มีการ START/STOP ใหม่
3. **คีย์/ปุ่มค้างเมื่อหยุดกลางคัน** — หยุดหลัง `Press Key` หรือ `Left Down` โดยไม่มีแถว
   Release → Ctrl หรือปุ่มเมาส์ค้างตลอด → เพิ่ม `_pressed_keys`/`_pressed_btns`
   ตอน STOP จะปล่อยทุกคีย์/ปุ่มที่ยังกดอยู่ให้อัตโนมัติ
4. **Wait for Image หยุดช้า** — ลูกรอ 0.5 วิ ต่อรอบ → ใช้ generation check เหมือนกัน

### ✨ เพิ่มใหม่
- **📸 ปุ่มจับภาพ (ลากกรอบบนจอ)** — ทำไฟล์ .png สำหรับ Image Click จากในโปรแกรม
  โดยไม่ต้องเปิด editor ภายนอก (โปรแกรมหดตัวเอง → ลากกรอบโปร่งใส → ตั้งชื่อไฟล์)
- **🎚️ Threshold รายแถว** — ปรับความมั่นใจของ Image Click/Wait for Image ต่อแถวได้:
  `ไฟล์.png@x,y,w,h#90` (90%) หรือ `ไฟล์.png#65` (65% ทั้งจอ) — ค่าเริ่มต้น 80%

### 📚 เอกสาร
- เพิ่ม **docs/TUTORIAL.md + .html** — คู่มือฉบับสมบูรณ์ 10 บท พร้อมสารบัญและ FAQ

## [1.5.0] — 2026-09-27

> ฟีเจอร์ชุดนี้ศึกษาและคัดสรรจาก [automouseclick.com](https://www.automouseclick.com/)

### ✨ เพิ่มใหม่ — Action ชุดใหม่ในตาราง
- **Scroll Up / Scroll Down** — เลื่อนล้อเมาส์ตามจำนวนจังหวะ (ใส่ในช่อง Additional เช่น `3`)
- **Double Left Click / Double Right Click** — ดับเบิลคลิกที่พิกัด
- **คลิกแบบ Modifier** — Ctrl+Click, Shift+Click, Alt+Click, Ctrl+Right Click
- **Move Mouse** — ย้ายเมาส์ไปพิกัดโดยไม่คลิก
- **Move Mouse by Offset** — ย้ายแบบสัมพัทธ์จากตำแหน่งปัจจุบัน (X,Y = ระยะเปลี่ยนแปลง)
- **Save Cursor / Restore Cursor** — จำตำแหน่งเมาส์แล้วย้อนกลับมาภายหลัง
- **Type Text** — พิมพ์ข้อความ (รองรับภาษาไทย) ตรงช่อง Additional
- **Launch App** — เปิดโปรแกรม/ไฟล์/เว็บไซต์ (เช่น `https://example.com`)
- **Wait for Image** — รอจนกว่าภาพที่ระบุจะปรากฏบนจอ (timeout 30 วิ)
- **Beep** — เสียงเตือนจากสมาร์ต
- **อัด scroll ตอน RECORD** — บันทึกการเลื่อนล้อเมาส์เป็นแถว Scroll Up/Down อัตโนมัติ

### ✨ เพิ่มใหม่ — ตัวเลือกการเล่น
- **ดีเลย์สุ่ม** — ใส่ Secs แบบ `1-3` เพื่อสุ่มดีเลย์ 1–3 วิ (กันจังหวะเครื่องจักรจนเกินไป)
- **ตัวคูณความเร็ว** — 0.25× / 0.5× / 1× / 2× / 4×
- **จำนวนรอบของสคริปต์ทั้งชุด** — ช่อง "รอบ" (0 = ไม่จำกัด)
- **คืนเมาส์จุดเดิม** — ติ๊กแล้วเมื่อจบรอบ เมาส์จะกลับมาที่ตำแหน่งเริ่มเล่น

### 🧪 ทดสอบ
- เพิ่ม 12 unit tests (รวม 41): `delay_range`, ชุด action ใหม่ครบและไม่ซ้ำ

  (space, enter, esc, ctrl, shift, alt, win, f1–f12, ลูกศร, pgup/pgdn, prtsc ฯลฯ)
  และรหัส virtual key ตัวเลข
- **จับพิกัดเมาส์อัตโนมัติ** — ดับเบิลคลิกช่อง X/Y นับถอยหลัง 3 วิ แล้วใส่ตำแหน่งเมาส์ปัจจุบัน
- **แก้ค่าในตาราง** — ดับเบิลคลิกช่องอื่นเปิดหน้าต่างแก้ค่า (Action เป็น dropdown)
- **Checkbox เปิด/ปิดรายแถว** (☑/☐) และเครื่องมือจัดการแถว: เพิ่ม / ลบ / เลื่อนขึ้นลง / ล้างทั้งหมด
- **Save / Load สคริปต์ .json** + autosave (`macro_conf.json`) ตอนปิดโปรแกรม
- **Live statusbar** — พิกัดเมาส์และคีย์ที่กดล่าสุดแบบสด + ไฮไลต์แถวที่กำลังเล่น
- **คีย์ลัดในโปรแกรม** — F6 / F8 / F9 / F10 / Delete
- **เมนูไอคอน** — Save, Load, Settings, About, Help, Exit (ภาษาไทยทั้งหมด)

### 📦 Build & การแจกจ่าย

- `requirements.txt` — pynput>=1.7.6 (ติดตั้งจริงเวอร์ชัน 1.8.2 บน Python 3.14.7)
