## [1.21.0] — 2026-09-29

### ✨ เพิ่มใหม่ (ดึงจาก ROADMAP)
- **🔁 If Loop (เงื่อนไขนับรอบ)** — Additional = เลขรอบ N เช่น `3`: รอบที่ 3 ขึ้นไป → ข้ามแถวถัดไปจำนวน N (คอลัมน์ Repeat) เหมาะกับ "รอบแรก setup รอบถัดไปข้าม" · GUI และ CLI ทำงานเหมือนกัน
- **🕐 If Time (เงื่อนไขเวลา)** — Additional = `HH:MM` เช่น `22:30`: ผ่านเวลากำหนดของวันนี้แล้ว → ข้าม N แถวถัดไป (Repeat) เช่น "หลัง 22:30 งานค้างคืนให้หยุดทำ" · GUI และ CLI
- **🗂️ หัวข้อ Section (จัดระเบียบตาราง)** — คลิกขวา → "เปลี่ยนเป็นหัวข้อ Section" / "เพิ่มหัวข้อ Section": แถวเป็นป้ายชื่อกลุ่มสีเทาเข้ม ไม่ถูกเล่น ไม่นับเลขลำดับ ไม่หน่วง — สคริปต์ยาวอ่านง่ายขึ้นทันที
- **📐 กฎเดียวของเงื่อนไขทั้งหมด** — คอลัมน์ Repeat ของแถวเงื่อนไข = **จำนวนแถวที่ข้าม** เสมอ (If Image / Else If Image / If Loop / If Time ใช้กฎเดียวกัน)

### 🐛 แก้ (จากการรันเดโม่จริง)
- **CLI เล่นแถวเงื่อนไขซ้ำเป็น action** — เมื่อเงื่อนไขไม่ทำงาน (ยังไม่ถึงรอบ/เวลา) โค้ดเดิมไหลลง do_step แล้วโดนเตือน "action ยังไม่รองรับใน CLI" ทั้งที่มันคือเงื่อนไขที่รองรับ → แถวเงื่อนไข `continue` เสมอ พร้อม print เหตุผลทุกกรณี (ยังไม่ถึง/ผ่านแล้ว/ค่าไม่ถูก)
- **CLI เช็คการข้ามหลังดีเลย์** — แถวที่ถูกสั่งข้ามเดิมยังหน่วงตาม Mins/Secs ก่อนถูกข้าม (GUI ข้ามก่อนดีเลย์แล้ว) → ย้ายไปเช็คก่อนดีเลย์ ทั้งสองโหมดทำงานเหมือนกัน

### 📘 เอกสาร
- TUTORIAL บทที่ 5B ใหม่: เงื่อนไขนับรอบ/เวลา + หัวข้อ Section พร้อมตัวอย่างทำตามได้ · เดโม่ `examples/10_conditions_v21.json` (Beep ล้วน ปลอดภัย ทดสอบรัน 3 รอบจริงแล้ว)

### 🧪 ทดสอบ

  layout (แนวเดียวกับ AutoHotkey) — อังกฤษ/ไทย/อิโมจิ/สัญลักษณ์ถูกต้องทุกตัว

  OS อื่น fallback ไปทาง pynput เหมือนเดิม) · `\n` ในข้อความ = กด Enter
