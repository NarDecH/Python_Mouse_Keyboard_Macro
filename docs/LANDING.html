🖱️ Auto Mouse & Keyboard Macro

สั่งเมาส์และคีย์บอร์ดทำงานแทนคุณแบบอัตโนมัติ — อัดครั้งเดียว เล่นซ้ำได้ไม่จำกัด
ฟรี โอเพนซอร์ส ไม่มีโฆษณา ไม่มีล็อกอิน ไฟล์เดียวจบ

📦 ดาวน์โหลดสำหรับ Windows — ฟรี ⭐ ซอร์สโค้ดบน GitHub
ไม่ต้องติดตั้ง Pythonภาษาไทยเต็มรูปแบบ568 + 20 testsWindows · Linux · macOS

📸 หน้าตาโปรแกรม

ตารางคำสั่งแก้ได้ทีละแถว + ปุ่ม START / STOP / REPEAT / RECORD + โปรไฟล์หลายชุด

🚀 เริ่มใช้ใน 4 ขั้นตอน

  1. ดาวน์โหลด AutoMouseMacro.exe แล้วดับเบิลคลิก (ไม่ต้องติดตั้งอะไร)
  2. กด RECORD (F9) แล้วทำงานตามปกติ — โปรแกรมจดทุกคลิก/ทุกคีย์ให้เอง
  3. กด START (F6) เล่นรอบเดียว หรือ REPEAT เล่นวนซ้ำ — STOP (F8) หยุดทันที
  4. Save เก็บเป็นไฟล์ .json เปิดมาเล่นซ้ำวันไหนก็ได้ หรือรันผ่าน Task Scheduler

✨ ทำอะไรได้บ้าง

  • อัด + เล่นซ้ำ คลิกเมาส์ ลาก พิมพ์ไทย/อังกฤษ กดคีย์ สกรอลล์ — พร้อมดีเลย์สุ่มกันจับ pattern
  • คลิกตามภาพ (Image Click) — ระบุรูป .png โปรแกรมหาบนจอแล้วคลิกให้เอง มีกรอบค้นหา + ปรับความมั่นใจรายแถว + รอซ้ำได้ (`5s`)
  • สคริปต์ตัดสินใจเองได้ — เงื่อนไขครบวงจร: If Image · If Pixel Color · If Variable · If Loop · If Time + ตัวแปร {ชื่อ} และคลิปบอร์ด
  • ตารางจัดการง่าย — ลากสลับแถวด้วยเมาส์ · Undo/Redo (Ctrl+Z/Y) · หัวข้อกลุ่มย่อ/ขยาย · คอลัมน์หมายเหตุ · ค้นหาแทนที่ทั้งหมด
  • ขยายด้วยปลั๊กอิน — เขียนไฟล์ Python สั้น ๆ วางใน plugins/ เป็น Action ใหม่ทันที (มี 10 ตัวให้: Screenshot, Toast, Webhook ฯลฯ)
  • ปุ่มลัดทำงานทุกที่ — F1–F4 สลับสคริปต์ทันที, F6 เล่น, F8 หยุด, F9 อัด, F10 วนไม่จำกัด
  • เล่นอัตโนมัติตามเวลา — ทุก N นาที หรือรายวันตอน HH:MM
  • สุ่มลำดับ/สัดส่วนแถว — งานที่ไม่อยากให้จังหวะซ้ำเดิมทุกรอบ
  • โหมด watchdog — สคริปต์จบแล้วเริ่มใหม่เองวนไม่จำกัด + safety timeout หยุดเองหลังเล่น N นาที + --validate ตรวจสคริปต์ก่อนปล่อยงานจริง
  • ปลั๊กอินเป็นเงื่อนไขได้ด้วย (v2.16) — เงื่อนไขสำเร็จรูปให้ครบ: Internet Up · Process Running · Window Exists · Window Focused · File Newer Than · HTTP Status — เช่น "API พร้อมและหน้าต่างงานยังโฟกัส = ค่อยทำงานต่อ"
  • 🚀 Launcher คู่สคริปต์ (v2.16) — Save สคริปต์แล้วกดเมนู 🚀 ได้ .bat + .lnk ดับเบิลคลิกเล่นสคริปต์นั้นทันที ไม่ต้องเปิดโปรแกรมหลัก — งานประจำวันสบายขึ้น
  • ⏱ ไทม์ไลน์การเล่น (v2.16) — ปุ่มในหน้าต่าง 📝 Log เห็นทุกแถวของรอบล่าสุด (เล่น/ข้าม/เหตุผล/เวลา) ดีบั๊กสคริปต์เงื่อนไขซ้อน ๆ ได้ในหน้าเดียว
  • 🔊 Beep ตั้งค่าได้ (v2.17) — เสียงแจ้งผ่านงานอัตโนมัติ: ความถี่/ระยะ/จำนวนครั้ง กำหนดรายแถวได้ (`freq=1000 dur=200 count=3`) — ไม่ใส่ = เสียงระบบเดิมเป๊ะ
  • 🔀 เงื่อนไข OR (v2.19) — เงื่อนไขทุกชนิดคั่น || ได้ สายใดจริงก่อน = จริงทั้งนิพจน์ (short-circuit) · ผสม && ได้ (แน่นกว่า) · เก็บผลรวมเป็นตัวแปรด้วย >ชื่อ · .ahk export/import ครบ
  • 🎲 สุ่มลำดับกลุ่ม (v2.18) — แบ่งสคริปต์เป็นหัวข้อกลุ่มแล้วสลับลำดับกลุ่มทั้งก้อน (แถวภายในกลุ่มเรียงเดิมเสมอ) · เลือกเฉพาะกลุ่มที่ต้องการหลายกลุ่มคั่น comma — เหมาะงานที่ต้องสุ่มโปรแกรมทุกวัน
  • 🧪 Dry-run เฉพาะกลุ่ม (v2.18) — คลิกขวาหัวข้อ → ซ้อมเดินเฉพาะกลุ่มนั้น ไม่แตะเมาส์/คีย์จริง (เงื่อนไข/ตัวแปร/บล็อกเดินจริง) — ตรวจสคริปต์ยิ่งใหญ่ทีละกลุ่มก่อนปล่อยงานจริง
  • Log + สถิติ — บันทึกทุกการเล่นรายวัน ดูย้อนหลังและสรุปสถิติได้ในโปรแกรม
  • Self-check ตอนเปิด — ตรวจเมาส์/hotkey/OpenCV/สิทธิ์ admin ให้รู้ปัญหาตั้งแต่แรก

⌨️ ใช้ผ่านคอมมานด์ไลน์ (สำหรับงานอัตโนมัติ)

py auto_macro.py script.json --loop            # วนไม่จำกัด
py auto_macro.py script.json --shuffle         # สุ่มลำดับแถวทุกรอบ
py auto_macro.py script.json --watchdog 10     # จบแล้วเริ่มใหม่เอง (พัก 10 วิ)
py auto_macro.py script.json --max-minutes 60  # safety timeout: หยุดเองหลังเล่น 60 นาที
py auto_macro.py script.json --validate        # ตรวจสคริปต์อย่างเดียวไม่เล่น (exit 1 เมื่อพบแถวมีปัญหา)
py auto_macro.py script.json --stop-file C:\stop.flg   # สร้างไฟล์ = หยุดทันที

เหมาะกับ Windows Task Scheduler — ตั้งเวลาเปิดเครื่องแล้วให้โปรแกรมทำงานแทนคุณทั้งวัน
