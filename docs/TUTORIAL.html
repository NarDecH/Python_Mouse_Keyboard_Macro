บทที่ 1 — ติดตั้งและเริ่มต้น

1.1 ติดตั้ง

แบบ .exe (ง่ายสุด): ดาวน์โหลด AutoMouseMacro.exe จากหน้า Releases แล้วดับเบิลคลิก — ไม่ต้องติดตั้ง Python

py -m pip install -r requirements.txt   # pynput (+ opencv-python Pillow สำหรับ Image Click)
py auto_macro.py                        # หรือดับเบิลคลิก run.bat
เครื่องที่ python ไม่ทำงาน (Windows Store stub) ให้ใช้ py แทนเสมอ

1.2 รู้จักหน้าจอ

1.3 คีย์ลัด (กดได้แม้ไม่โฟกัสหน้าต่าง)

F6 เล่น • F8 หยุด • F9 บันทึก • F10 วนไม่จำกัด • Delete ลบแถว

บทที่ 2 — อัดสคริปต์แรกใน 60 วินาที

  1. กด RECORD (หรือ F9) — สถานะเปลี่ยนเป็น "กำลังบันทึก"
  2. คลิกที่จอ 2–3 จุด, เลื่อนล้อเมาส์, พิมพ์อะไรสักหน่อย
  3. กด F9 อีกครั้ง — ทุกเหตุการณ์ถูกจดลงตารางพร้อมจังหวะเวลา (Secs)
  4. กด F6 (START) → โปรแกรมเล่นซ้ำทุกอย่างที่เพิ่งทำ
  5. ลองกด REPEAT ให้วนตลอด → หยุดด้วย F8 (หยุดทันที ไม่ต้องรอจบแถว)
💡 ช่อง ☑ หน้าแถว = เปิด/ปิดแถวนั้น (แถวที่ ☐ จะถูกข้ามตอนเล่น)

บทที่ 4 — Action ทั้งหมดและเมื่อไหร่ควรใช้

  • เมาส์พื้นฐาน: Left/Right/Middle Click, Down, Up (Down→Up = ลาก drag)
  • คลิกพิเศษ: Double Click, Ctrl+Click, Shift+Click, Alt+Click, Ctrl+Right Click
  • การเคลื่อนที่: Move Mouse (ไปพิกัด), Move Mouse by Offset (ขยับสัมพัทธ์)
  • จดจำตำแหน่ง: Save Cursor → … → Restore Cursor (คู่ต้องใช้ด้วยกัน)
  • คีย์บอร์ด: Tap/Press/Release Key, Type Text
  • ภายนอก: Launch App (เปิดโปรแกรม/เว็บ)
  • อัจฉริยะ: Image Click (หาภาพแล้วคลิก + ตั้ง {img_x}/{img_y} ให้เอง), Wait for Image (รอภาพก่อนทำต่อ), Wait for Pixel Color (v1.18 — รอจุดสี), Read Pixel Color (v2.5 — อ่านสีเก็บตัวแปร)
  • เงื่อนไข (v1.17+): If Image (ไม่เจอ → ข้าม N แถว), Else If Image (สองทาง A/B — ดูบทที่ 5A), If Loop / If Time (นับรอบ/เวลา — บทที่ 5B), If Pixel Color (สีจุด), If Variable (เทียบตัวแปร — v2.5), หัวข้อ Section
    กฎเดียวกันทุกตัว: Repeat = จำนวนแถวที่ข้ามเมื่อเงื่อนไขไม่จริง
  • เสียง: Beep (จุดเช็คว่าสคริปต์ถึงไหน)
หลักคิด: พิกัด vs ภาพ
ปุ่มอยู่ตำแหน่งเดิมเสมอ → ใช้พิกัด X,Y (เร็ว) • หน้าต่างเลื่อนได้ → ใช้ Image Click (ทนทานกว่า)

บทที่ 5 — Image Click + Search Area + Threshold

5.1 เตรียมภาพ

กดปุ่ม 📸 จับภาพ (ลากกรอบบนจอ) → โปรแกรมหดตัวเอง → ลากครอบปุ่ม/วัตถุที่ต้องการ → ตั้งชื่อไฟล์ (เช่น play.png) — เซฟไว้ที่โฟลเดอร์โปรแกรม

5.2 ใช้งาน

เพิ่มแถว Image Click → Additional ใส่:

รูปแบบความหมาย
play.pngค้นทั้งจอ, threshold 80%
play.png@100,200,500,300ค้นเฉพาะกรอบ (100,200) กว้าง 500 × สูง 300 — เร็วกว่าและแม่นกว่า
play.png@100,200,500,300#90เดิม + ต้องมั่นใจ 90% ขึ้นไป
play.png#65ทั้งจอ, ผ่อนเป็น 65% (ภาพเปลี่ยนบ่อย)
💡 Search Area คือเครื่องมือที่ทำให้ Image Click ใช้งานจริงได้ — กรอบแคบ = เร็วขึ้นหลายเท่า + ไม่คลิกภาพเดียวกันที่อยู่มุมอื่น
threshold สูง (90–95) = เข้มงวด, ต่ำ (60–70) = ทนสี/แสงเปลี่ยน แต่เสี่ยงคลิกผิด

บทที่ 5A — เงื่อนไข: If Image และ Else If Image (v1.17+)

If Image — ไม่เจอแล้วข้าม

  • Additional = ไฟล์ .png (ใช้ Search Area/threshold ได้เหมือน Image Click)
  • ภาพเจอ → เล่นแถวถัดไปตามปกติ
  • ภาพไม่เจอ → ข้ามแถวถัดไป N แถว (N = ค่าคอลัมน์ Repeat ของแถว If Image)
  • เหมาะกับ: "ถ้าโฆษณาเด้ง → กดปิด, ไม่เด้ง → เล่นต่อ"

Else If Image — เงื่อนไขสองทาง (v1.18)

วางหลังกลุ่ม A เพื่อแบ่งสคริปต์เป็นสองทาง:

แถว 1  If Image (btn.png)      ← เช็คเงื่อนไข
แถว 2-3  ...กลุ่ม A (เล่นเมื่อเจอภาพ)
แถว 4  Else If Image Repeat = 2   ← Repeat = จำนวนแถวกลุ่ม B ที่จะข้าม
แถว 5-6  ...กลุ่ม B (เล่นเมื่อไม่เจอภาพ)
  • If Image เจอ → เล่นกลุ่ม A หมด → Else ข้ามกลุ่ม B (ตาม Repeat ของ Else)
  • If Image ไม่เจอ → กลุ่ม A ถูกข้าม → Else เล่นกลุ่ม B ต่อ
  • ⚠️ Else ใช้ผล If Image ล่าสุด เสมอ — วางคู่กันให้ถูกลำดับ

Wait for Pixel Color — รอจุดสี (v1.18)

  • Additional: x,y #RRGGBB เช่น 300,300 #ffffff — รอจนจุดนั้นมีสีใกล้เคียง
  • หน่วงก่อนตรวจใส่ใน Secs (รองรับ 1-3 สุ่มได้) · รอสูงสุด 30 วิ แล้วข้ามต่อ
  • เหมาะกับ: รอ progress bar เต็ม, รอไฟสถานะเขียว, รอปุ่มเปลี่ยนสี
แบบฝึกหัด (ไม่คลิก ปลอดภัย): เปิด examples/07_conditions.json → กด START → ลองบัง/เลิกบังหน้าต่างที่มี target.png แล้วเล่นใหม่ — เส้นทางต้องเปลี่ยน → เปิด 📊 Stats ดู Action ที่กินเวลามากสุด

บทที่ 5B — เงื่อนไขนับรอบ/เวลา และหัวข้อ Section (v1.21)

🔁 If Loop — รอบที่ N ขึ้นไปให้ข้าม

  • Additional = เลขรอบ เช่น 3 → รอบที่ 3, 4, 5, ... แถวถัดไปถูกข้าม
  • จำนวนแถวที่ข้าม = คอลัมน์ Repeat (กฎเดียวกับ If Image)
  • เหมาะกับ: "รอบแรก setup (เปิดโปรแกรม/ล็อกอิน) รอบถัดไปข้าม" — วาง If Loop 2 แล้วตั้ง Repeat = จำนวนแถว setup

🕐 If Time — ผ่านเวลากำหนดแล้วให้ข้าม

  • Additional = HH:MM เช่น 22:30 → เลยเวลานี้ของวันนี้แล้ว → ข้ามแถวถัดไป N แถว (Repeat) · ยังไม่ถึง → เล่นต่อปกติ
  • เหมาะกับ: "หลัง 22:30 งานค้างคืนให้หยุดทำ"

🗂️ หัวข้อ Section — จัดระเบียบสคริปต์ยาว

  • คลิกขวาที่แถว → เปลี่ยนเป็นหัวข้อ Section (หรือแทรกแถวหัวข้อใหม่)
  • เป็นป้ายชื่อกลุ่มพื้นสีเทาเข้ม: ไม่ถูกเล่น ไม่นับเลข # ไม่หน่วง — แก้ข้อความได้ด้วยดับเบิลคลิกช่อง Additional · สลับกลับเป็นแถวธรรมดาได้
แบบฝึกหัด (ปลอดภัย เล่นจบเอง): รัน py auto_macro.py examples/10_conditions_v21.json --loops 3 → รอบ 3 แถว "รอบ 3 ขึ้นไป..." หายไป = If Loop ทำงาน → แก้ If Time เป็น 1 นาทีถัดไป แล้วเล่นใหม่ — แถวถัดไปถูกข้ามทันที → ลองคลิกขวาแถว → เปลี่ยนเป็นหัวข้อ → START — แถวนั้นไม่ถูกเล่น

📁📂 ย่อ/ขยายกลุ่ม + 🎨 สีแถว (v1.22)

  • ย่อกลุ่ม: คลิกขวาที่หัวข้อ → 📁 ย่อกลุ่มนี้ — แถวสมาชิกหายจากจอ หัวข้อขึ้นป้าย (ย่อ N แถว) แต่แถวซ่อนยังถูกเล่นตามปกติทุกอย่าง (รวม Save/Load) — กดซ้ำ 📂 ขยายกลุ่มนี้ ได้ลำดับเดิมเป๊ะ
  • ลบหัวข้อที่ย่ออยู่ = โปรแกรมขยายคืนก่อนแล้วจึงลบ (แถวไม่หาย) · ย้ายกลุ่ม = เลือกหัวข้อแล้วกด ▲▼ (เลื่อนทั้งก้อน)
  • สีแถวช่วยอ่าน: เหลืองอ่อน = เงื่อนไข, ม่วงอ่อน = คีย์บอร์ด, ฟ้าอ่อน = Action พิเศษ, ขาว-ฟ้าสลับ = แถวเมาส์ — สีเป็นแค่การจัดระเบียบ ไม่มีผลกับการเล่น
  • 💡 ปุ่ม 🕐 เวลานี้ (+15 นาที) บนแถบเครื่องมือ — เติม HH:MM ให้แถว If Time ที่เลือกอัตโนมัติ (แบบเดียวกับปุ่ม 🎨 จับสี)

บทที่ 6 — ตัวเลือกการเล่นขั้นสูง

ตัวควบคุมความหมาย
ความเร็ว 0.25×–4×คูณ/หารดีเลย์ทุกแถว (ช้า-เร็วโดยไม่แก้ตาราง)
รอบ N (0=ไม่จำกัด)จำนวนรอบของสคริปต์ทั้งชุด
วนซ้ำไม่จำกัด (F10)เท่ากับตั้งรอบ 0
คืนเมาส์จุดเดิมจบแต่ละรอบ เมาส์กลับจุดที่กด START
ดีเลย์สุ่ม: Secs = 1-3 สุ่มทุกรอบ — จำเป็นกับงานที่ "จังหวะหุ่นยนต์เป๊ะเกิน" ถูกจับได้

บทที่ 7 — โปรไฟล์ และ เล่นอัตโนมัติตามเวลา

โปรไฟล์: แถบใต้เมนู → ＋ สร้าง "เกมA", "งานรายวัน" ฯลฯ — สลับแล้วตารางเปลี่ยนตาม (เซฟชุดเดิมอัตโนมัติ) เก็บใน macro_profiles.json

Schedule: ปุ่ม ⏰ เล่นอัตโนมัติ... → โหมด "ทุก N นาที" หรือ "ทุกวัน HH:MM" — เวลานัดหมายถึง โปรแกรมจะเล่นสคริปต์เอง (หยุดได้ด้วย F8 เสมอ)

บทที่ 8 — CLI: เล่นสคริปต์โดยไม่เปิดหน้าต่าง

py auto_macro.py script.json              # เล่นรอบเดียว
py auto_macro.py script.json --loop       # วนไม่จำกัด
py auto_macro.py script.json --loops 10   # 10 รอบ
py auto_macro.py script.json --speed 2    # เร็ว 2 เท่า
py auto_macro.py script.json --max-minutes 60  # safety timeout: หยุดเองหลังเล่น 60 นาที (v2.4)
py auto_macro.py script.json --validate   # ตรวจสคริปต์อย่างเดียวไม่เล่น (v2.4)
py engine_cli.py script.json              # CLI ย่อย engine ล้วน (ไม่แตะ tkinter)
py engine_cli.py s.jsonl --json-lines     # อ่านสคริปต์ 1 แถว JSON ต่อบรรทัด (v2.2)
  • หยุด: กด F8/Esc (ได้แม้คอนโซลไม่โฟกัส) หรือ Ctrl+C
  • แสดงความคืบหน้าทีละแถว — เหมาะกับ Windows Task Scheduler
  • v2.2: ทำงานครบทุก action — Image Click/If Image/Else/Wait for Image ค้นภาพจริงใน CLI ได้แล้ว (ไฟล์หาย = รายงานเหตุผลแล้วเล่นต่อ)
  • v2.3–2.4: --version · --validate (ตรวจสคริปต์ไม่เล่น, exit 1 เมื่อพบปัญหา) · --max-minutes N (safety timeout: หยุดเองหลังเล่น N นาที)

17.1 Dry-run — ซ้อมก่อนเล่นจริง

หลักการ: เดินสคริปต์ "จริงทุกอย่างยกเว้น input" — เงื่อนไข/บล็อก/ดีเลย์/ตัวแปรคำนวณจริง ทุกเส้นทาง แต่แถว input จริงถูกแทนด้วยข้อความ "DRY-RUN: จะ…" แทนทำจริง — ใช้ก่อนปล่อยงานค้างคืน (schedule/watchdog) ไม่เสี่ยงคลิกผิดตอนหลับ

ใหม่ v2.10.1 — รายงานเป็นไฟล์: จบ dry-run แล้วโปรแกรมเขียนสำเนาทั้งเส้นทางลง dry_report_วันที่.txt ข้างโปรแกรม พร้อมสรุปนับรายการที่จะทำจริง (เช่น สรุปจะทำจริง: Left Click ×2, Type Text ×1) — ถูกหยุดกลางคันก็บันทึก ส่วนที่เดินผ่าน + ระบุ "ถูกหยุดกลางคัน" · Wait for Image/Pixel รายงานทันทีไม่รอจริง (dry-run จบเร็วเสมอ) · รายงานเขียนทน error ทุกจุด เขียนไม่ได้โปรแกรมไม่พัง

17.2 ผลเงื่อนไขเป็นตัวแปร — โทเคน >ชื่อ

ทุกแถวเงื่อนไขเติม >ชื่อ ท้าย Additional ได้ — ผลเงื่อนไข "1" (จริง) / "0" (ไม่จริง) ถูกเก็บลงตัวแปร แถวถัดไปใช้ต่อทันที:

If Imageปุ่มเขียว.png >เจอเจอ → {เจอ}=1, ไม่เจอ → {เจอ}=0
If Pixel Color300,300 #ffffff >สีตรงสีตรง → {สีตรง}=1
If Variablen > 3 >พ้นเกณฑ์n>3 → {พ้นเกณฑ์}=1
If Loop10 >ครบ 10 รอบรอบ ≥ 10 → {ครบ 10 รอบ}=1

ต่อยอด: If Variable แยกเส้นทางต่อ (เจอ = 1) · Block Start ครอบทั้งก้อน (if เจอ = 1) · ข้อความอ้างผลได้ (Type Text ผลตรวจ: {เจอ}) · ชื่อห้ามเป็นคำ on/of/and · โทเคนถูกตัดออกก่อนค้นภาพ · ตัวแปรเริ่มใหม่ทุกครั้งที่เริ่มเล่น

18. เครื่องมือ log (v2.11) — เก็บถาวรรายเดือน · เคลียร์วันเก่า

log การเล่น (macro_log_วันที่.txt) และรายงาน dry-run (dry_report_วันที่.txt) หมุนรายวัน และ log ของวันนี้ถูกตัดเหลือ 500 บรรทัดล่าสุด — งานที่อยากเก็บย้อนนานกว่านั้น ใช้เครื่องมือใหม่ในหน้าต่าง 📝 Log:

  • เก็บถาวรวันเก่า — ย้าย log/dry-report ทุกไฟล์ที่ไม่ใช่วันนี้ลง log_archive/ แยกโฟลเดอร์รายเดือนจากวันที่ในชื่อไฟล์ เช่น log_archive/2026-09/macro_log_2026-09-20.txt — เก็บตลอดไป ไม่มีการลบ
  • ล้างวันเก่า... — ลบไฟล์เก่าทั้งหมด (ยกเว้นของวันนี้) — ถามยืนยันก่อนเสมอ ลบแล้วเรียกคืนไม่ได้ ถ้าไม่แน่ใจให้กดเก็บถาวรแทน
  • dropdown "ไฟล์:" เห็นทั้ง log และรายงาน dry-run แล้ว (เดิมมีแต่ log)

ตั้งจัดการอัตโนมัติ (Settings): ☑ "จัดการ log วันเก่าตอนปิดโปรแกรม" + จำนวนวัน 1–365 + ☑ เก็บถาวรแทนลบ — ค่าเริ่มต้นปิดอยู่ ไม่แตะไฟล์จนกว่าจะเปิด · ไฟล์ของ "วันนี้" ไม่เคยถูกแตะทั้งสองวิธี — เพราะยังเขียนอยู่

19. ผู้เล่นคิวแบบ GUI (v2.12) — 📑 Run Queue เล่นหลายไฟล์ในโปรแกรม

หัวข้อ 17 รันคิวผ่านคอนโซล (--queue / 🗂️ Queue Bat) — v2.12 เพิ่มเมนู 📑 Run Queue ให้เล่นคิวในโปรแกรมเลย เห็นผลทุกไฟล์แบบสด ไม่ต้องเปิดคอนโซล:

  • เริ่มเล่น — เลือกไฟล์ลิสต์ .txt (รูปแบบเดิม ใช้ลิสต์เดียวกับ --queue ได้) → กด ▶ เริ่มเล่นคิว — ตรวจทุกไฟล์ก่อน (ไฟล์พัง = ยกเลิกทั้งคิว ไม่เล่นสักแถว เหมือน CLI) แล้วเล่นทีละไฟล์: แถวกำลังเล่นสีน้ำเงิน + ป้ายไฟล์ปัจจุบัน + กล่องผลลัพธ์ CLI แบบทันที (เก็บ 200 บรรทัดล่าสุด)
  • สถานะรายไฟล์ — กำลังเล่น… (น้ำเงิน) · จบครบ ✔ (เขียว) · ถูกหยุด (ส้ม) · พบปัญหา exit N (แดง — คิวยังเล่นไฟล์ถัดไปต่อ) · ตรวจไม่ผ่าน/ไม่พบไฟล์ (แดง — ยกเลิกทั้งคิว) · — (ยกเลิก) (เทา)
  • หยุด 2 ระดับ — "⏹ หยุดไฟล์นี้" = หยุดไฟล์ปัจจุบันแล้วเล่นไฟล์ถัดไปต่อ (กลไก --stop-file ของ CLI โดยสร้าง stop-file รายไฟล์) · "⏹⏹ หยุดทั้งคิว" = หยุดไฟล์ปัจจุบัน + ยกเลิกไฟล์ที่เหลือ · F8/Esc = หยุดทั้งคิว (ความหมายเดียวกับ CLI เดิม)

เกร็ด: จบคิวแล้วกด ▶ เริ่มใหม่ได้เลย · ปิดหน้าต่างขณะเล่น = ถามก่อนแล้วหยุดทั้งคิว · ปิดโปรแกรมขณะเล่น = สั่งหยุดทั้งคิวอัตโนมัติ · เธรดเล่นใช้ CLI จริงทุกโลจิก — ระหว่างเล่น คิวยังแก้ตาราง/โหลดสคริปต์อื่นได้ตามปกติ

20. Plugin API v3 (v2.13) — เงื่อนไขของคุณเอง: CONDITION_NAME + check

หัวข้อ 11 ต่อยอด Custom Action (v1.16) — ตอนนี้ plugin เขียนเป็น เงื่อนไข ได้ด้วย: ประกาศ CONDITION_NAME = "ชื่อ" + def check(ctx, row) -> bool (ตัวอย่างจริง: plugins/file_exists.py — เงื่อนไข "File Exists"):

  • กติกาเดียวกับเงื่อนไขทุกชนิด — จริง = เล่นต่อ · ไม่จริง = ข้าม N แถว (N = Repeat) · โทเคน >ชื่อ ท้ายแถวเก็บผลลงตัวแปรได้ · ไฟล์เดียวมีทั้ง ACTION_NAME และ CONDITION_NAME ได้ (ชื่อต้องต่างกัน) · ชื่อซ้ำ = ข้ามไฟล์พร้อมสาเหตุ
  • ใช้ 2 ทาง — คอลัมน์ Action = ชื่อเงื่อนไข (dropdown เพิ่มอัตโนมัติ สีแถวหมวดเงื่อนไข) หรือ Block Start เขียน if File Exists C:\\work\\done.flag (ผสม && กับเงื่อนไขสีจุด/ตัวแปร/ภาพได้)
  • ข้อควรรู้ — 🔍 Validate/--validate/ตรวจตอน START รู้จักชื่อเงื่อนไข plugin · Dry-run เรียก check จริง (เขียนให้เป็นอ่านอย่างเดียว — ห้ามคลิก/พิมพ์) · .ahk export เขียนเป็น comment ทั้งบล็อก · คู่มือเต็ม: PLUGINS.md · ตัวอย่าง: examples/14_condition_plugin.json

21. เงื่อนไข plugin สำเร็จรูป + ปุ่ม 🧩 + --dry-report (v2.14)

หัวข้อ 12 ต่อจาก Plugin API v3 — เงื่อนไขพร้อมใช้มากับโปรแกรมแล้ว 4 ตัว: File Exists · Internet Up (เช็คเน็ต — Additional = host[:port] และ/หรือ Ns ค่าเริ่มต้น 1.1.1.1:443) · Process Running (tasklist/pgrep — ไม่สนตัวพิมพ์/นามสกุล .exe) · Window Exists (EnumWindows ctypes ล้วน / xdotool บน Linux):

  • ใช้เป็น Action หรือ Block Start — เช่น if Internet Up && Process Running chrome = เน็ตขึ้นและ Chrome รันอยู่เท่านั้นถึงเล่นบล็อก · OS ที่ไม่มีเครื่องมือ = เท็จ โปรแกรมไม่พัง
  • ปุ่ม 🧩 เงื่อนไข plugin — เลือกชื่อจาก dropdown + พิมพ์อาร์กิวเมนต์ กดแทรกได้แถวใหม่ (Repeat = จำนวนแถวที่ข้ามเมื่อไม่จริง) · เลขลำดับ + สี cond อัตโนมัติ · Ctrl+Z ย้อนได้
  • CLI --dry-report PATH — เลือกไฟล์รายงาน Dry-run เอง ({date} = วันที่วันนี้, เขียนต่อท้ายไฟล์เดิม, ใช้กับ --dry-run เท่านั้น) · เมนู 🧪 Dry-run ก็เลือกพาธได้ · ตัวอย่าง: examples/15_system_conditions.json · คู่มือ: PLUGINS.md

22. เล่นเฉพาะกลุ่มหัวข้อ (v2.15) — คลิกขวาที่หัวข้อ + --only-section

สคริปต์ยาวที่แบ่งเป็นขั้น ๆ ด้วยหัวข้อ Section (⬛) ตอนนี้ทดสอบ/รันทีละกลุ่มได้:

  • คลิกขวาที่แถวหัวข้อ → "▶ เล่นกลุ่มนี้อย่างเดียว" — เล่นเฉพาะแถวที่เปิดใช้ (☑) ในกลุ่มนั้น จนถึงหัวข้อถัดไป แล้วหยุดเอง — ผ่าน player จริงสายเดียวกับ START ทุกอย่าง (validate/STOP/ไฮไลต์/log/เลขรอบ ครบ) ไม่ต้องปิดแถวอื่นเอง
  • แถวในกลุ่มที่ย่ออยู่ก็เล่นครบ — ย่อกลุ่มไว้ประหยัดจอแล้วเล่นได้ปกติ (สัญญาเดียวกับ v1.22) · กลุ่มไม่มีแถวที่เปิดใช้ = เตือน statusbar แล้วจบเงียบ ไม่เริ่มเล่น
  • CLI --only-section ชื่อ — หาหัวข้อชื่อตรงเป๊ะ → print ช่วงแถว + จำนวน แล้วเล่นเฉพาะกลุ่มนั้น · ชื่อไม่พบ = เตือนแล้วเล่นทั้งหมดตามปกติ · สายเดียวกับเล่นทั้งหมด — เอาไปผสม --queue/watchdog ได้

23. ย้ายกลุ่มทั้งก้อน (v2.15.1) — Group order

จัดลำดับการเล่นทีละกลุ่มโดยไม่ต้องลากทีละแถว:

  • คลิกขวาที่หัวข้อ → "⬆ ย้ายกลุ่มขึ้น" / "⬇ ย้ายกลุ่มลง" (หรือคลิกหัวข้อแล้วกด Alt+↑/↓ หรือปุ่ม ▲▼) — สลับก้อน [หัวข้อ + แถว + แถวย่อใน stash] กับกลุ่มข้างเคียงทั้งก้อน
  • แถวย่อเดินตามหัวข้อของตัวเองเสมอ — ย่อไว้แล้วย้าย แถวไม่หลุดกลุ่ม · Block Start/End คร่อมกลุ่ม = ปฏิเสธพร้อมเตือน (กันบล็อกพัง) · Ctrl+Z ย้อนได้

24. 🚀 Launcher คู่สคริปต์ (v2.16) — ดับเบิลคลิก = เล่นทันที

งานรันซ้ำทุกวันไม่ต้องเปิดโปรแกรมหลักอีกต่อไป (ต่อยอด Export Bat / Queue Bat):

  • Save สคริปต์ → กดเมนู 🚀 Launcher — ได้ไฟล์คู่ข้างสคริปต์: ชื่อ.bat (มี exe ข้าง ๆ = start exe, ไม่มี = fallback py auto_macro.py + pause) และ ชื่อ.lnk (Windows — มี exe = ชี้ตรง exe ได้ไอคอนโปรแกรม, ไม่มี = ชี้ .bat)
  • ดับเบิลคลิก .lnk (หรือ .bat) = เล่นสคริปต์นั้นทันที · เติมอาร์กิวเมนต์ได้ท้ายบรรทัดใน .bat เช่น --loop --speed 2
  • .lnk ใช้ PowerShell (Windows เท่านั้น) — OS อื่นได้ .bat/.sh อย่างเดียว ใช้ได้เหมือนกัน

25. ⏱ ไทม์ไลน์เหตุการณ์ (v2.16) — ดีบั๊กเงื่อนไขซ้อนหลายชั้น

เปิด 📝 Log → ปุ่ม "⏱ ไทม์ไลน์การเล่นล่าสุด":

  • ตารางต่อเหตุการณ์: เวลา · ผล (▶ เล่น/⏭ ข้าม/ℹ อื่น ๆ) · แถว i/N · เหตุการณ์ · วินาที — เขียว = เล่น, ส้ม = ข้าม (เหตุผลอยู่คอลัมน์เหตุการณ์), เทา = ข้อมูลระบบ
  • dropdown ย้อนทุกครั้งที่เล่น + หัวสรุป "เล่น N · ข้าม N" — เปิดมาชี้รายการล่าสุดให้เอง · ข้อมูลจาก log เดิม (parse_log_timeline) — ปิด log ไว้ = ไม่มีข้อมูล

26. 🔌 เงื่อนไข plugin ชุมชนรอบใหม่ (v2.16)

  • Window Focused — หน้าต่างที่โฟกัสอยู่ตอนนี้มีข้อความในชื่อ = จริง (ต่างจาก Window Exists ที่สแกนทุกหน้าต่าง)
  • File Newer Than — ไฟล์A > ไฟล์B (A ใหม่กว่า B) หรือ ไฟล์ Ns (แก้ภายใน N วินาที) · พาธมีช่องว่างใช้ได้
  • HTTP Status — URL [รหัส] [Ns] เช่น https://api.local/health 200 3s — ไม่ใส่รหัส = 2xx ใด ๆ · ใช้เป็น Action หรือ Block Start && ได้เหมือนเงื่อนไข plugin ทุกตัว
