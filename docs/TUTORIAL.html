บทที่ 1 — ติดตั้งและเริ่มต้น

1.1 ติดตั้ง

แบบ .exe (ง่ายสุด): ดาวน์โหลด AutoMouseMacro.exe จากหน้า Releases แล้วดับเบิลคลิก — ไม่ต้องติดตั้ง Python

py -m pip install -r requirements.txt   # pynput (+ opencv-python Pillow สำหรับ Image Click)
py auto_macro.py                        # หรือดับเบิลคลิก run.bat
เครื่องที่ python ไม่ทำงาน (Windows Store stub) ให้ใช้ py แทนเสมอ

1.3 คีย์ลัด (กดได้แม้ไม่โฟกัสหน้าต่าง)

F6 เล่น • F8 หยุด • F9 บันทึก • F10 วนไม่จำกัด • Delete ลบแถว

บทที่ 2 — อัดสคริปต์แรกใน 60 วินาที

  1. กด RECORD (หรือ F9) — สถานะเปลี่ยนเป็น "กำลังบันทึก"
  2. คลิกที่จอ 2–3 จุด, เลื่อนล้อเมาส์, พิมพ์อะไรสักหน่อย
  3. กด F9 อีกครั้ง — ทุกเหตุการณ์ถูกจดลงตารางพร้อมจังหวะเวลา (Secs)
  4. กด F6 (START) → โปรแกรมเล่นซ้ำทุกอย่างที่เพิ่งทำ
  5. ลองกด REPEAT ให้วนตลอด → หยุดด้วย F8 (หยุดทันที ไม่ต้องรอจบแถว)
💡 ช่อง ☑ หน้าแถว = เปิด/ปิดแถวนั้น (แถวที่ ☐ จะถูกข้ามตอนเล่น)

บทที่ 4 — Action ทั้งหมดและเมื่อไหร่ควรใช้

  • เมาส์พื้นฐาน: Left/Right/Middle Click, Down, Up (Down→Up = ลาก drag)
  • คลิกพิเศษ: Double Click, Ctrl+Click, Shift+Click, Alt+Click, Ctrl+Right Click
  • การเคลื่อนที่: Move Mouse (ไปพิกัด), Move Mouse by Offset (ขยับสัมพัทธ์)
  • จดจำตำแหน่ง: Save Cursor → … → Restore Cursor (คู่ต้องใช้ด้วยกัน)
  • คีย์บอร์ด: Tap/Press/Release Key, Type Text
  • ภายนอก: Launch App (เปิดโปรแกรม/เว็บ)
  • อัจฉริยะ: Image Click (หาภาพแล้วคลิก), Wait for Image (รอภาพก่อนทำต่อ), Wait for Pixel Color (v1.18 — รอจุดสี)
  • เงื่อนไข (v1.17+): If Image (ไม่เจอ → ข้าม N แถว), Else If Image (สองทาง A/B — ดูบทที่ 5A), If Loop / If Time (นับรอบ/เวลา — บทที่ 5B), หัวข้อ Section
  • เสียง: Beep (จุดเช็คว่าสคริปต์ถึงไหน)
หลักคิด: พิกัด vs ภาพ
ปุ่มอยู่ตำแหน่งเดิมเสมอ → ใช้พิกัด X,Y (เร็ว) • หน้าต่างเลื่อนได้ → ใช้ Image Click (ทนทานกว่า)

บทที่ 5 — Image Click + Search Area + Threshold

5.1 เตรียมภาพ

กดปุ่ม 📸 จับภาพ (ลากกรอบบนจอ) → โปรแกรมหดตัวเอง → ลากครอบปุ่ม/วัตถุที่ต้องการ → ตั้งชื่อไฟล์ (เช่น play.png) — เซฟไว้ที่โฟลเดอร์โปรแกรม

5.2 ใช้งาน

เพิ่มแถว Image Click → Additional ใส่:

รูปแบบความหมาย
play.pngค้นทั้งจอ, threshold 80%
play.png@100,200,500,300ค้นเฉพาะกรอบ (100,200) กว้าง 500 × สูง 300 — เร็วกว่าและแม่นกว่า
play.png@100,200,500,300#90เดิม + ต้องมั่นใจ 90% ขึ้นไป
play.png#65ทั้งจอ, ผ่อนเป็น 65% (ภาพเปลี่ยนบ่อย)
💡 Search Area คือเครื่องมือที่ทำให้ Image Click ใช้งานจริงได้ — กรอบแคบ = เร็วขึ้นหลายเท่า + ไม่คลิกภาพเดียวกันที่อยู่มุมอื่น
threshold สูง (90–95) = เข้มงวด, ต่ำ (60–70) = ทนสี/แสงเปลี่ยน แต่เสี่ยงคลิกผิด

บทที่ 5A — เงื่อนไข: If Image และ Else If Image (v1.17+)

If Image — ไม่เจอแล้วข้าม

  • Additional = ไฟล์ .png (ใช้ Search Area/threshold ได้เหมือน Image Click)
  • ภาพเจอ → เล่นแถวถัดไปตามปกติ
  • ภาพไม่เจอ → ข้ามแถวถัดไป N แถว (N = ค่าคอลัมน์ Repeat ของแถว If Image)
  • เหมาะกับ: "ถ้าโฆษณาเด้ง → กดปิด, ไม่เด้ง → เล่นต่อ"

Else If Image — เงื่อนไขสองทาง (v1.18)

วางหลังกลุ่ม A เพื่อแบ่งสคริปต์เป็นสองทาง:

แถว 1  If Image (btn.png)      ← เช็คเงื่อนไข
แถว 2-3  ...กลุ่ม A (เล่นเมื่อเจอภาพ)
แถว 4  Else If Image Repeat = 2   ← Repeat = จำนวนแถวกลุ่ม B ที่จะข้าม
แถว 5-6  ...กลุ่ม B (เล่นเมื่อไม่เจอภาพ)
  • If Image เจอ → เล่นกลุ่ม A หมด → Else ข้ามกลุ่ม B (ตาม Repeat ของ Else)
  • If Image ไม่เจอ → กลุ่ม A ถูกข้าม → Else เล่นกลุ่ม B ต่อ
  • ⚠️ Else ใช้ผล If Image ล่าสุด เสมอ — วางคู่กันให้ถูกลำดับ

Wait for Pixel Color — รอจุดสี (v1.18)

  • Additional: x,y #RRGGBB เช่น 300,300 #ffffff — รอจนจุดนั้นมีสีใกล้เคียง
  • หน่วงก่อนตรวจใส่ใน Secs (รองรับ 1-3 สุ่มได้) · รอสูงสุด 30 วิ แล้วข้ามต่อ
  • เหมาะกับ: รอ progress bar เต็ม, รอไฟสถานะเขียว, รอปุ่มเปลี่ยนสี
แบบฝึกหัด (ไม่คลิก ปลอดภัย): เปิด examples/07_conditions.json → กด START → ลองบัง/เลิกบังหน้าต่างที่มี target.png แล้วเล่นใหม่ — เส้นทางต้องเปลี่ยน → เปิด 📊 Stats ดู Action ที่กินเวลามากสุด

บทที่ 5B — เงื่อนไขนับรอบ/เวลา และหัวข้อ Section (v1.21)

🔁 If Loop — รอบที่ N ขึ้นไปให้ข้าม

  • Additional = เลขรอบ เช่น 3 → รอบที่ 3, 4, 5, ... แถวถัดไปถูกข้าม
  • จำนวนแถวที่ข้าม = คอลัมน์ Repeat (กฎเดียวกับ If Image)
  • เหมาะกับ: "รอบแรก setup (เปิดโปรแกรม/ล็อกอิน) รอบถัดไปข้าม" — วาง If Loop 2 แล้วตั้ง Repeat = จำนวนแถว setup

🕐 If Time — ผ่านเวลากำหนดแล้วให้ข้าม

  • Additional = HH:MM เช่น 22:30 → เลยเวลานี้ของวันนี้แล้ว → ข้ามแถวถัดไป N แถว (Repeat) · ยังไม่ถึง → เล่นต่อปกติ
  • เหมาะกับ: "หลัง 22:30 งานค้างคืนให้หยุดทำ"

🗂️ หัวข้อ Section — จัดระเบียบสคริปต์ยาว

  • คลิกขวาที่แถว → เปลี่ยนเป็นหัวข้อ Section (หรือแทรกแถวหัวข้อใหม่)
  • เป็นป้ายชื่อกลุ่มพื้นสีเทาเข้ม: ไม่ถูกเล่น ไม่นับเลข # ไม่หน่วง — แก้ข้อความได้ด้วยดับเบิลคลิกช่อง Additional · สลับกลับเป็นแถวธรรมดาได้
แบบฝึกหัด (ปลอดภัย เล่นจบเอง): รัน py auto_macro.py examples/10_conditions_v21.json --loops 3 → รอบ 3 แถว "รอบ 3 ขึ้นไป..." หายไป = If Loop ทำงาน → แก้ If Time เป็น 1 นาทีถัดไป แล้วเล่นใหม่ — แถวถัดไปถูกข้ามทันที → ลองคลิกขวาแถว → เปลี่ยนเป็นหัวข้อ → START — แถวนั้นไม่ถูกเล่น

📁📂 ย่อ/ขยายกลุ่ม + 🎨 สีแถว (v1.22)

  • ย่อกลุ่ม: คลิกขวาที่หัวข้อ → 📁 ย่อกลุ่มนี้ — แถวสมาชิกหายจากจอ หัวข้อขึ้นป้าย (ย่อ N แถว) แต่แถวซ่อนยังถูกเล่นตามปกติทุกอย่าง (รวม Save/Load) — กดซ้ำ 📂 ขยายกลุ่มนี้ ได้ลำดับเดิมเป๊ะ
  • ลบหัวข้อที่ย่ออยู่ = โปรแกรมขยายคืนก่อนแล้วจึงลบ (แถวไม่หาย) · ย้ายกลุ่ม = เลือกหัวข้อแล้วกด ▲▼ (เลื่อนทั้งก้อน)
  • สีแถวช่วยอ่าน: เหลืองอ่อน = เงื่อนไข, ม่วงอ่อน = คีย์บอร์ด, ฟ้าอ่อน = Action พิเศษ, ขาว-ฟ้าสลับ = แถวเมาส์ — สีเป็นแค่การจัดระเบียบ ไม่มีผลกับการเล่น
  • 💡 ปุ่ม 🕐 เวลานี้ (+15 นาที) บนแถบเครื่องมือ — เติม HH:MM ให้แถว If Time ที่เลือกอัตโนมัติ (แบบเดียวกับปุ่ม 🎨 จับสี)

บทที่ 7 — โปรไฟล์ และ เล่นอัตโนมัติตามเวลา

โปรไฟล์: แถบใต้เมนู → ＋ สร้าง "เกมA", "งานรายวัน" ฯลฯ — สลับแล้วตารางเปลี่ยนตาม (เซฟชุดเดิมอัตโนมัติ) เก็บใน macro_profiles.json

Schedule: ปุ่ม ⏰ เล่นอัตโนมัติ... → โหมด "ทุก N นาที" หรือ "ทุกวัน HH:MM" — เวลานัดหมายถึง โปรแกรมจะเล่นสคริปต์เอง (หยุดได้ด้วย F8 เสมอ)

  • v2.2: ทำงานครบทุก action — Image Click/If Image/Else/Wait for Image ค้นภาพจริงใน CLI ได้แล้ว (ไฟล์หาย = รายงานเหตุผลแล้วเล่นต่อ)

บทที่ 10 — สำรอง/ย้ายเครื่อง และดูสถิติ

10.1 Backup อัตโนมัติ (v1.13+)

ปิดโปรแกรมทุกครั้งจะสำรองงาน + โปรไฟล์ทุกชุด + การตั้งค่าลง backups/backup_วันที่_เวลา.json และตัดไฟล์เก่าเหลือย้อนหลัง 7 วัน (ปรับได้ใน Settings) — เปิด/ปิดระบบนี้ได้ใน Settings

10.2 Export / Import (สำรองแบบควบคุมเอง)

Settings → ⬆️ Export = ไฟล์เดียวจบ เอาไปเปิดเครื่องอื่นด้วย ⬇️ Import — มีพรีวิวและถามยืนยันก่อนเสมอ

10.3 ดูสถิติ + กราฟ + สถิติราย Action (v1.18)

เมนู 📊 Stats — สรุปจาก log ทุกวัน (เล่น/ถูกหยุด/watchdog/แถวช้าสุด) + กราฟแท่ง 14 วันล่าสุด (เขียวเข้ม = เริ่มเล่น, เขียวอ่อน = เหตุการณ์) + ⏱ Action ที่ใช้เวลารวมมากสุด 5 อันดับ — หา bottleneck ของสคริปต์ได้ทันที

10.4 ตรวจว่าระบบพร้อมจริง

Settings → 🧪 ทดสอบระบบจริง = เมาส์ขยับเป็นสามเหลี่ยมแล้วคืนจุดเดิม + บี๊บ 2 ครั้ง — ถ้าไม่ขยับลอง Run as Administrator (ดู self-check ที่หัว Settings)

บทที่ 11 — แก้ปัญหาที่เจอบ่อย (FAQ)

อาการสาเหตุ/วิธีแก้
กด START แล้วไม่มีอะไรเกิดขึ้นตารางว่างหรือทุกแถวเป็น ☐ — เปิดแถวก่อน
คลิกผิดตำแหน่งหน้าจอ scaling ไม่ตรง → จับพิกัดใหม่ด้วยดับเบิลคลิก X/Y หรือเปลี่ยนไปใช้ Image Click
Image Click หาไม่เจอลด threshold (#70), ขยาย Search Area, หรือจับภาพใหม่ตอนหน้าจอสถานะเดียวกับตอนเล่น
กด STOP แล้ว Ctrl/เมาส์ยังค้างไม่ควรเกิดแล้ว (v1.7.1+) — โปรแกรมปล่อยคีย์/ปุ่มค้างให้อัตโนมัติทั้ง GUI และ CLI
กลัวแก้สคริปต์พังไม่ต้องกลัว — ปิดโปรแกรมแต่ละครั้งมี backup อัตโนมัติย้อนหลัง 7 วันใน backups/
เกมไม่รับคำสั่งเกมบางเกมกรอง injected input — ลองโหมด windowed หรือเกมนั้นใช้ไม่ได้
พิมพ์ไทยไม่ออกใช้ Action "Type Text" (ไม่ใช่เคาะคีย์ไทยบนแป้นจริง)
คีย์ลัดไม่ทำงานโปรแกรมอื่นจับ F6–F10 ไว้ — ดูสถานะที่ Settings
⚠️ ข้อควรระวังการใช้งาน
  • ทดสอบทีละแถวก่อนปล่อยวนอัตโนมัติจริง
  • ตั้งดีเลย์ให้พอสำหรับแอปที่ช้า (เปิดโปรแกรมให้ 1.5–2 วิ)
  • อย่าใช้กับเกม/ระบบที่ห้าม bot — ผิดกฎของผู้ให้บริการ
  • ปิด/หยุดด้วย F8 หรือปุ่ม Exit เพื่อให้ autosave ทำงาน

บทที่ 12 — ตัวแปรและคลิปบอร์ด (v1.19+)

12.1 ตัวแปรในสคริปต์ (Set Variable)

เพิ่ม Action Set Variable แล้วพิมพ์ในช่อง Additional:

พิมพ์ความหมาย
รอบ = 1ตั้งค่า (ข้อความหรือตัวเลขก็ได้)
รอบ += 1บวกเพิ่ม (ตัวเลข — ตัวแปรใหม่เริ่มที่ 0)
รอบ -= 1ลดลง

เรียกใช้ด้วย {ชื่อตัวแปร} ได้ในทุกช่อง — X, Y, Additional, Mins, Secs, Repeat เช่น แถว Beep วาง Secs = {รอบ} → ดีเลย์ตามค่าตัวแปร

py auto_macro.py examples/08_variables.json     # เดโม่ทำตาม (ไม่คลิก ปลอดภัย)
  • ชื่อตัวแปรเป็นไทย/อังกฤษได้ ห้ามขึ้นต้นด้วยตัวเลข และห้ามมีช่องว่าง
  • ตัวแปรเริ่มใหม่ทุกครั้งที่เริ่มเล่น (กด START/REPEAT รอบใหม่ = ล้างค่า)
  • พิมพ์ชื่อผิด เช่น {รอบ2} โปรแกรมคง {รอบ2} เดิมไว้ให้เห็น ไม่เดาค่าเอง

12.2 คลิปบอร์ด (Set Clipboard / Read Clipboard) (v1.20+)

ActionAdditionalทำอะไร
Set Clipboardข้อความ (ใช้ {ตัวแปร} ได้) ใส่ข้อความลงคลิปบอร์ด — วางต่อในแอปอื่นด้วย Ctrl+V ได้เลย
